Multiple pages per sheet

Fit several pages from a PDF onto each A4 page to make a smaller, print-friendly document. For example, place 4 pages on each sheet to turn a 100-page PDF into 25 pages.

PDF pages are embedded as PDF content rather than converted to images. Horizontal order fills each row from left to right; vertical order fills each column from top to bottom.
